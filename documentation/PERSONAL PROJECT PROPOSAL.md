1. Introduction
In order to gain practical skills in data cleansing, data analysis, KPI reporting, supplier performance analysis, and dashboard construction, this personal project focuses on examining purchase-order data using Microsoft Excel. 
In order to help purchasing, supplier management, cost analysis, quality monitoring, and operational decision-making, the project aims to show how structured procurement data may be converted into useful business information.
2. Background
Accurate and timely data is essential to modern supply-chain and procurement processes. When assessing suppliers and finding areas for improvement, organisations must comprehend supplier performance, purchasing costs, negotiated prices, product quality, compliance, and order status. 
A structured purchase-order dataset with supplier details, order and delivery dates, item categories, order status, quantities, unit pricing, negotiated prices, defective units, and compliance data is used in this project. 
An interactive Excel dashboard will be used to clean, validate, analyse, and show the data.
3. Project Aim
The project's goal is to create an Excel-based solution for purchase-order analysis and reporting that shows how data can be used practically to assess supplier performance, analyse purchasing costs, spot quality and compliance problems, and assist with procurement-related decision-making.
4. Project Objectives
The undertaking will: 
1. Open the provided purchase-order dataset and review it. 
2. Determine and fix problems with data quality. 
3. Make dates, supplier names, categories, and numerical values consistent. 
4. Make calculated fields for performance analysis, quality, and purchasing. 
5. Use Excel functions such as SUMIFS, COUNTIFS, IF, XLOOKUP, and other suitable formulas. 
6. Analyse supplier, category, order status, and purchase performance using pivot tables. 
7. Determine important KPIs, or key performance indicators. 
8. Examine negotiated rates and any cost savings. 
9. Examine failure rates and defective units. 
10. Assess performance in terms of compliance. 
11. Create an Excel dashboard that is interactive. 
12. Recognise significant patterns, trends, and possible dangers. 
13. Make suggestions in light of the analysis. 
14. Record the project's methods and conclusions. 
15. Post the finished product and its accompanying documentation on GitHub.
5. Dataset
777 purchase orders with the following details are included in the project dataset: • ID of the purchase order 
• Provider 
• Date of Order 
• Date of Delivery 
• Category of Items 
• Status of Orders 
• Amount 
• The cost per unit 
• The price that was negotiated 
• Units that are defective 
• Adherence 
For analytical and instructional reasons, the dataset will be handled as a sample business dataset. 
There won't be any assertions that the dataset accurately reflects procurement information from a particular company.
6. Methodology
The project will follow a structured data-analysis process:
Data Preparation → Data Profiling → Data Cleaning → Data Validation → Data Transformation → Analysis → KPI Development → Dashboard Development → Findings → Recommendations → Documentation
Data Cleaning
The dataset will be checked for:
•	Duplicate records
•	Missing values
•	Incorrect data formats
•	Inconsistent supplier or category names
•	Numerical-data issues
•	Date-format issues
•	Invalid or inconsistent values
Data Transformation
Additional analytical fields will be developed where appropriate, including:
•	Original Cost
•	Negotiated Cost
•	Potential Savings
•	Discount %
•	Defect Rate %
•	Delivery Days
Potential savings will be used rather than actual savings because the dataset does not provide evidence that calculated savings were actually realised.
Delivery duration will be analysed using the available order and delivery dates. A late-delivery measure will not be calculated because the dataset does not contain a target or promised delivery date.
Data Analysis
Excel formulas and PivotTables will be used to analyse:
•	Supplier performance
•	Item-category performance
•	Purchasing expenditure
•	Negotiated pricing
•	Potential savings
•	Order status
•	Delivery duration
•	Defective units
•	Defect rates
•	Compliance performance
Dashboard Development
An interactive Excel dashboard will be developed using appropriate KPI cards, charts, tables, conditional formatting, and filters/slicers to provide a concise overview of purchasing and supplier performance.

9. Business Relevance
While the dataset represents a sample collection, the analytical methodology maintains applicability to procurement, supply-chain, logistics, and operational contexts. Evaluating supplier performance, purchase spending, agreed-upon pricing, product standards, regulatory adherence, and order fulfillment status yields valuable insights for assessing suppliers and developing procurement strategies. A more comprehensive procurement analysis would necessitate supplementary data including payment arrangements, agreement values, fulfillment timelines, shipping expenses, vendor service quality metrics, and prior supplier track records. Such variables fall beyond the parameters of the present dataset.

13. Limitations
The project is based on a sample purchase-order dataset and therefore does not contain actual supplier contracts, payment terms, transport costs, delivery lead-time targets, or real organisational procurement information.
Consequently, the project will demonstrate the analytical process rather than provide actual procurement recommendations for a specific organisation.
